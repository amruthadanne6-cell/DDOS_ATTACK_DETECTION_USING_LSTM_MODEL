About the Project

Project Title:
Design and Development of a Working Prototype for DDoS Attack Detection Using an LSTM-Based Traffic-Flow Classifier.

Technology Used:
HTML, CSS, JavaScript, Python, TensorFlow/Keras and LSTM.

Objective:
To develop a prototype that can classify network traffic flows and help identify Distributed Denial of Service (DDoS) attacks using sequential traffic features.

Important:
This webpage is a front-end demonstration. Real LSTM-based detection requires a trained model and a connected backend.
